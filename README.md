# Aristotle – World Biology Olympiads Bank

Public site of the World Biology Olympiads Bank (eisatopon.gr): biology olympiad questions — the International Biology Olympiad (IBO) theoretical papers first — in English, with every option, table and figure, statements only (no answers).

Live: https://eisatopon.github.io/biology-olympiads-bank/

This repository holds only the files the site loads. The questions remain the work of their authors and organising committees; the IBO examination papers are published by the International Biology Olympiad under CC BY-NC-SA 4.0 (https://creativecommons.org/licenses/by-nc-sa/4.0/), and this site is shared under the same terms, non-commercially, with credit to the IBO.
Sister projects: [Mathematical](https://eisatopon.github.io/national-olympiads-bank/), [Physics](https://eisatopon.github.io/physics-olympiads-bank/), [Chemistry](https://eisatopon.github.io/chemistry-olympiads-bank/) and [Informatics](https://eisatopon.github.io/informatics-olympiads-bank/) Olympiads Banks.
